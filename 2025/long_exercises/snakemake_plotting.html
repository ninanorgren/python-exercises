Create Snakemake workflow to plot SNP frequencies

Author

Nina Norgren

Published

August 22, 2025

Background

Snakemake is a workflow manager built in Python that is commonly used in bioinformatics to parallelize and execute jobs. A job can be a shell command or python code. This exercise uses both command line tools and python scripts to build a pipeline for extracting and visualizing SNPs from several separate VCF files.

Task

For each VCF file:

  • Extract all variants in the genomice region chr4:100000-200000 using bcftools and write new VCF files for each sample

  • Write a small python script that takes all 10 VCF files as command line inputs and outputs a csv file.

Command:

myscript.py <outputfile> <inputfile1.vcf> <inputfile2.vcf>

Output file format:

Samplename rs1234 rs5678
Sample1 0/1 1/1
Sample2 0/0 0/1

Use bcftools to extract regions, python script to merge files together. Plot the results (frequencies between cases and controls, violinplot or boxplot, use scipy to calculate p-values and add to plot)
